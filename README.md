# HydroJungle — Wash & Iron

A Django-based laundry service application developed as a seminar project. The application models a simple customer workflow for placing laundry orders and tracking delivery.

## Project scope

- Customer login and signup workflow
- Laundry order placement
- Pricing logic for selected clothing items
- Order data managed through Django models
- Delivery workflow and order-related pages

## Technology

- Python
- Django
- HTML, CSS and JavaScript
- SQLite / Django-supported database configuration

## Current status

Academic project. Update this section as features are tested, refined and deployed.

## Run locally

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install the dependencies listed in `requirements.txt` if the file is present.
4. Run database migrations with `python manage.py migrate`.
5. Start the development server with `python manage.py runserver`.
